# AI Code Assistant 💻

Full-featured AI-powered coding assistant powered by **Mimo v2.5 Pro**.

## Features

- ⚡ **Generate** — Create production-ready code from descriptions
- 📖 **Explain** — Line-by-line code explanations for learning
- 🐛 **Debug** — Find and fix bugs with detailed analysis
- 🔧 **Refactor** — Improve code quality and readability
- 🔄 **Convert** — Translate between 14 programming languages
- 🔍 **Review** — Thorough code review with security, performance, best practices
- 🚀 **Optimize** — Performance improvements with Big-O analysis
- 🧪 **Test** — Generate comprehensive unit and edge case tests

## Supported Languages

JavaScript, TypeScript, Python, Rust, Go, Java, C++, C#, PHP, Ruby, Swift, Kotlin, Dart, Scala

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript** + **Tailwind CSS**
- **Lucide React** (icons)
- **Mimo v2.5 Pro** (AI model)

## Getting Started

```bash
npm install
npm run dev
```
